# 吉他从入门到精通

这是一套按学习路径编排的中文吉他教程。前七篇建立木吉他与电吉他共通能力，第八篇按乐器和目标分流，之后重新汇合到高级乐理、即兴、听力、创作和完整音乐能力。

建议按顺序学习。每一篇的“完成标准”比阅读进度更重要。遇到动作疼痛时先停止练习，检查姿势和用力，不要靠忍耐推进。

## 如何使用

1. 每周选择一篇中的一到两个小节，不要按篇数赶进度。
2. 每次练习先调音，再用低速节拍器检查动作。
3. 先录一遍基线，再练习，最后录一遍对比。
4. 只有达到篇末完成标准，才进入下一篇。
5. 完成第七篇后选择 A 或 B 路线，也可以先主修一条，再补另一条。

## 完整能力模型

教程中的“精通”不等于弹得快。完整能力由九个维度共同构成：

- Technique
- Rhythm
- Fretboard
- Theory
- Ear
- Repertoire
- Improvisation
- Tone
- Composition

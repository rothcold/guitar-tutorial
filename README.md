# 吉他从入门到精通

这是一套按学习路径编排的中文吉他教程。前七篇建立木吉他与电吉他共通能力，第八篇按乐器和目标分流，之后重新汇合到高级乐理、即兴、听力、创作和完整音乐能力。

建议按顺序学习，但篇末完成标准只用于自我检查，不是阅读下一篇的硬性门槛。每篇先按证据选择一个训练阶段，再执行七个训练日，不需要同时练完本篇全部练习卡。每篇周期都是估算，掌握较快可以缩短，学习较慢或主动安排休息日可以延长。遇到动作疼痛时先停止练习，检查姿势和用力，不要靠忍耐推进。

在线版本：[guitar.rothcold.me](https://guitar.rothcold.me)

教程源文件位于 [`docs/`](docs/)。面向维护者的项目约定见 [`AGENTS.md`](AGENTS.md)。

## 本地网站

网站使用 Astro 构建，需要 Node.js 22.12.0 或更高版本和 npm。

```text
script/setup
npm run dev
```

提交前运行 `script/lint` 和 `script/test`。CI 使用 `script/cibuild` 执行同一套校验。

## Vercel 发布

1. 在 Vercel 中导入 GitHub 仓库 `rothcold/guitar-tutorial`，生产分支保持 `main`。这是纯静态 Astro 站点，不需要 Vercel adapter；构建命令为 `npm run build`，输出目录为 `dist`。
2. 添加 `guitar.rothcold.me` 自定义域名，并按 Vercel 提示在 Cloudflare 完成 DNS 配置。启用项目的 Web Analytics。
3. 首次生产部署不要设置 `SITE_INDEXING_ENABLED`，或将它设为 `false`。运行 GitHub Actions 中的 `Production smoke`，选择 `disabled`。
4. 首次 smoke 通过后，在 Vercel 的 Production 环境将 `SITE_INDEXING_ENABLED` 设为 `true` 并重新部署。环境变量只对新部署生效。
5. 再次运行 `Production smoke` 并选择 `enabled`。本地也可以运行 `script/smoke https://guitar.rothcold.me enabled`。

## 如何使用

1. 先查看篇内阶段表，选择当前最缺的一种证据，再选择 25、45 或 90 分钟档。
2. 按“训练日 1 至训练日 7”的角色顺序推进，同一周期只练所选阶段。休息后从下一个训练日顺延。
3. 每次练习先调音。演奏和节奏任务使用篇内速度，听力、创作和录音任务按次数、时限或产出物执行。
4. 连续 3 遍达到节奏、放松、音准、干净度和当前专项要求后，只增加速度、音数、方向、技巧或效果中的一项。
5. 每周至少保留一次短录音、谱例、分析表或工程版本，并只记录一个最需要修正的问题。
6. 篇末“已经获得的证据”“下周期继续维护”“可选巩固”用于判断当前状态，不是进阶门槛。
7. 完成第七篇后选择 A 或 B 路线。第十四篇只要求实际操作主修路线，另一条路线理解信号与安全原则即可。

## 完整能力模型

教程中的“精通”不等于弹得快。完整能力由九个维度共同构成：

- Technique
- Rhythm
- Fretboard
- Theory
- Ear
- Repertoire
- Improvisation
- Tone
- Composition

# 吉他从入门到精通

这是一套按学习路径编排的中文吉他教程。前七篇建立木吉他与电吉他共通能力，第八篇按乐器和目标分流，之后重新汇合到高级乐理、即兴、听力、创作和完整音乐能力。

建议按顺序学习，但篇末完成标准只用于自我检查，不是阅读下一篇的硬性门槛。每篇周期都是估算，掌握较快可以缩短，学习较慢或主动安排休息日可以延长。遇到动作疼痛时先停止练习，检查姿势和用力，不要靠忍耐推进。

教程源文件位于 [`docs/`](docs/)。面向维护者的项目约定见 [`AGENTS.md`](AGENTS.md)。

## 本地网站

网站使用 Astro 构建，需要 Node.js 22.12.0 或更高版本和 npm。

```text
npm install
npm run dev
```

提交前运行 `npm run check` 和 `npm run build`。

## 如何使用

1. 先选择 25、45 或 90 分钟档，再按篇内的“训练日 1 至训练日 7”顺序推进。
2. 每次练习先调音。演奏和节奏任务使用篇内指定的节拍器速度，听力、创作和录音任务按次数、时限或产出物执行。
3. 每周至少保留一次短录音、谱例、分析表或工程版本，并只记录一个最需要修正的问题。
4. 篇末完成标准用于判断当前状态。你可以继续阅读，同时按需要重复训练日或延长周期。
5. 完成第七篇后选择 A 或 B 路线，也可以先主修一条，再补另一条。

## 完整能力模型

教程中的“精通”不等于弹得快。完整能力由九个维度共同构成：

- Technique
- Rhythm
- Fretboard
- Theory
- Ear
- Repertoire
- Improvisation
- Tone
- Composition
